# NOTIFICATIONS DOMAIN

> Multi-channel notification delivery (WhatsApp, Email, SMS, Push, In-App, Webhook).

## Responsibility
- Owns: notification delivery, channel routing, preferences, templates
- Does NOT own: notification content (generated by other domains)

## Boundaries
- Inbound: All domains (via notification intents)
- Outbound: WhatsApp (Twilio), Email (Resend), SMS (Twilio), Push (FCM), In-App (WebSocket)

## Status
- Maturity: 40%
- Extraction: Architecture complete (B11A), Runtime pending (B11B)
- Portal: None

## Domain Model
- **Entities**: Notification, NotificationTemplate, DeliveryLog
- **Value Objects**: Channel, NotificationStatus, DeliveryStatus, Priority
- **Aggregates**: Notification (root: Notification, invariants: delivery state machine)
- **Events**: notification.requested, notification.delivered, notification.failed, notification.read
- **Policies**: Channel routing, retry logic, quiet hours, fallback chains
