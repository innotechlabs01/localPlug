# Archive — spec-v1

This folder preserves the **v1 (technology-based) specification** of LocalPlug,
captured on 2026-07-11 before the platform documentation was restructured into the
layered + hybrid model now living in `docs/platform/`.

## Contents
- `../../MASTER_SPEC.md` — the original 30-section Master Specification (v1.0.0). It is the
  ancestral "Constitution" and remains a useful reference, but is superseded by
  `../../00-CONSTITUTION.md`.
- `restructure-attempt/` — an intermediate (incomplete) restructure attempt from the
  same session. Preserved for traceability; not authoritative.

## Why this exists
Per platform policy, documentation is **migrated, never deleted**. When the docs moved
from a technology-based layout (`01-product`…`10-engineering`) to the layered platform
layout, the previous version was moved here rather than removed.

The v2 structure and reading order are defined in `../../PLATFORM_INDEX.md`.
