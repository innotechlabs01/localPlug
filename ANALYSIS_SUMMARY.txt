  orders.arrival_time          → Reservation.arrivalTime

  orders.payment_status        → Reservation.paymentStatus
  orders.package_price         → Reservation.totalAmount
  orders.created_at            → Reservation.createdAt
  orders.updated_at            → Reservation.updatedAt

REQUIRES TRANSFORMATION:
  orders.customer_name         → Reservation.guest.firstName + lastName
                                 (Split "Sofía Martínez" → "Sofía", "Martínez")
  
  orders.flight_number+airline → Reservation.flightInfo
                                 (Concatenate: "AV124 — Arriving 14:30")
  
  orders.customer_notes        → Reservation.specialRequests
                                 (Partial mapping - might have other info)
  
  orders.destination_address   → Reservation.selectedHotel
                                 (Mapping to hotel/pickup location)
  
  orders.status                → Reservation.status
                                 (Value mapping: new→pending, etc)

MISSING / NOT STORED:
  Reservation.guest.id         ← No customer table, derive from email or auto-ID

  Reservation.service.includes ← Not in database, need package metadata table
  Reservation.paymentMethod    ← Not stored (would need payments table)
  Reservation.transactionId    ← orders.payment_id exists but no payments table
  Reservation.vipStatus        ← Derive from: orders.priority OR orders.package_price
